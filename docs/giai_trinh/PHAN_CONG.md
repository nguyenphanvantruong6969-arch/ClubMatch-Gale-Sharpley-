# Phân công công việc (mẫu để học sinh tự điền)

> **Mẫu trống.** Bảng dưới do hai học sinh thực hiện đề tài tự điền; không ai khác điền hộ. Phần mềm và các số liệu trong bộ
> tài liệu này là dữ liệu mô phỏng.

| Thành viên | Họ tên | Mã nguồn | Nghiên cứu | Ghi chú |
|---|---|---|---|---|
| Thành viên 1 | | | | |
| Thành viên 2 | | | | |

Cách điền gợi ý (tự chọn cách viết, không bắt buộc):

- Cột **Mã nguồn**: phần việc liên quan tới phần mềm (ví dụ module, tệp, kiểm thử).
- Cột **Nghiên cứu**: phần việc liên quan tới bài nghiên cứu (ví dụ thu thập tài liệu, thiết kế khảo sát, phân tích, viết).
- Cột **Ghi chú**: ngày, bằng chứng đi kèm (tệp, commit, biên bản).

Nguồn đối chiếu có sẵn nếu cần: `docs/nhat_ky_ai/NHAT_KY_AI_DE_DOC.md` (ai làm phần nào theo ghi chép trong kho mã).
